# Context Memory

This folder keeps only the minimum memory needed before reading code.

Keep:

- `project_context.md`
  - current truth only
- `phase_list.md`
  - ordered list of phases
- `phases/phase_*.md`
  - short records of what mattered in each phase

Rules:

- keep it short
- write only what helps preserve correctness and intent
- do not duplicate code structure line by line
- add a new phase only when the project enters a clearly new development era
